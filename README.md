# 🚀 AI Career GPS – Skill Gap Analyzer

##  Overview  
AI Career GPS is an intelligent career analysis system that helps users understand how their current skills align with real-world roles such as Software Development, Machine Learning, and Data Analysis.

Instead of just analyzing resumes, the system provides **structured insights, actionable roadmaps, and future simulations** to guide users toward their desired career paths.

---

## ✨ Features  

-  **Role Match Scores**  
  Quantifies how well a user fits different career roles  

-  **Skill Gap Analysis**  
  Identifies missing or weak skills for each role  

-  **Personalized Roadmap**  
  Step-by-step plan to improve and reach target roles  

-  **Project Suggestions**  
  Recommends projects to strengthen practical experience  

-  **Recruiter POV**  
  Highlights strengths, weaknesses, and shortlist probability  

-  **Before vs After Simulation**  
  Shows how specific improvements (e.g., learning DSA) impact career readiness

## ⚙️ Getting Started (Run Locally)

### 1. Clone the repository
git clone https://github.com/lavanya-125/Career-GPS-Skill-Gap-Analyser.git

cd Career-GPS-Skill-Gap-Analyser


---

### 2. Install dependencies

npm install


---

### 3. Create a `.env` file  

In the root directory, create a `.env` file and add:


API_KEY=your_api_key_here


---

### 4. Start the server

node server.js


---

### 5. Open in browser  
Go to:

http://localhost:3002


---

##  How It Works  

1. User inputs resume file or skills  
2. Backend sends data to AI model  
3. AI returns structured insights  
4. Results are displayed in sections:
   - Role match  
   - Skill gaps  
   - Roadmap  
   - Recruiter insights  
   - Simulation
